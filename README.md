SOs — Solomon's OS
An OS-style interface for the TI-84 Plus CE.

SOs is an experimental calculator interface project that brings supported programs, calculator files, and useful TI-84 reference information together in one place.
Features
- Programs menu — Browse supported programs detected on the calculator and select a program to launch.
- Files browser — Explore calculator variables and view available file information. Supported versions may provide archive, unarchive, or delete actions.
- TI-84 reference — Quick reference material for graphing, mathematics, statistics, probability, lists, matrices, programming, and memory.
- Solomon's Python — Intended integration with Solomon's Python; availability depends on the version and how it has been integrated.
The TI-84 reference is informational. It does not mean SOs replaces the calculator's built-in operating system or reimplements every native feature.

Getting started
1. Run SOs from the calculator's program list.
2. Use the main menu to select Programs, Files, or the reference/tools section.
3. Follow the on-screen prompts to browse items and return to the menu.
The available options may vary by version.
Platform
- Target: TI-84 Plus CE
- Project name: SOs (Solomon's OS)
- Status: Work in progress
Compatibility with other calculator models, OS versions, and program types is not guaranteed. Some features may be experimental or incomplete.
Important
Back up important calculator programs and data before testing file-management actions. Test archiving or deletion with disposable files first.
