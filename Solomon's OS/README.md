# SOs — Solomon's OS

**A calculator-focused interface for the TI-84 Plus CE.**

Welcome to **SOs**, Solomon's OS-style launcher designed to make your calculator's programs, files, and useful references easier to reach from one place.

## Welcome to SOs

SOs provides a central menu for navigating supported calculator content. Its exact features depend on the version installed on your calculator.

## Main sections

### Programs
Browse supported programs detected on the calculator and choose a program to launch. Whether a program can run depends on its type and compatibility with your calculator.

### Files
Browse calculator variables and inspect available information about them. In versions that support file actions, you may also be able to archive, unarchive, or delete a selected variable.

**Be careful when changing or deleting files.** Important programs and data can be lost. Test file actions with disposable files first.

### Tools and TI-84 Reference
Use the reference section to find guidance about common TI-84 Plus CE features, including:

- Graphing modes and graph controls
- Mathematics and numerical calculus
- Statistics and probability
- Lists and matrices
- Programming and memory
- Installed calculator apps

The reference is a guide to calculator features; it does not replace the calculator's built-in operating system or implement every TI-84 function inside SOs.

### Solomon's Python
Some SOs project builds are intended to work with Solomon's Python. Availability and functionality depend on whether that integration is included in the version installed.

## Getting started

1. Start **SOs** from the calculator's program list.
2. Use the on-screen menu to select a section.
3. Open **Programs** to find supported programs, **Files** to inspect calculator variables, or **Tools / TI-84 Reference** to consult the guide.
4. Follow the on-screen prompts to return to menus or select another item.

Menu labels and available actions can differ between versions.

## Compatibility

SOs is intended for the **TI-84 Plus CE** family. Compatibility with other calculator models, operating-system versions, program types, and installed apps is not guaranteed.

## Project status

SOs is an independent, evolving project. Some features may be experimental or incomplete, and behavior should be checked on the actual calculator. Keep backups of important calculator data before testing file-management features.
